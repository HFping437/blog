    # ES6 Proxy 与 Reflect 使用指南

    # 一、Proxy 概述

    # 定义与用途

    • 代理机制: 创建对象的代理，拦截并自定义对象的基本操作（如属性读写、函数调用等）
    • 元编程：用于实现高级抽象（如数据绑定、验证、日志记录等）

    # 基本语法

    let proxy = new Proxy(target, handler);
    • ​target：被代理的目标对象
    • ​handler：定义拦截行为（陷阱方法）的配置对象。

    # 二、Proxy 的 Handler 方法（陷阱方法）

    陷阱方法 触发场景 用途示例
    get(target, prop, receiver) 读取属性（如 proxy.prop） 动态计算属性、默认值处理
    set(target, prop, value, receiver) 设置属性（如 proxy.prop = 1） 数据验证、日志记录
    has(target, prop) in 操作符（如 prop in proxy） 隐藏敏感属性
    deleteProperty(target, prop) delete 操作（如 delete proxy.prop） 阻止删除操作
    apply(target, thisArg, args) 函数调用（如 proxy(...args)） 拦截函数执行、参数验证
    construct(target, args, newTarget) new 操作（如 new Proxy()） 拦截构造函数、初始化逻辑

    # 三、Proxy 应用场景

    # 数据验证

    const validator = {
  set(target, prop, value) {
    if (prop === 'age' && value < 0) throw new Error('年龄无效');
    return Reflect.set(target, prop, value);
  }
};
const user = new Proxy({}, validator);
user.age = 25;  // 成功
user.age = -5;  // 抛出错误

    # 属性访问日志

    const logger = {
  get(target, prop) {
    console.log(`读取属性: ${prop}`);
    return Reflect.get(target, prop);
  }
};
const data = new Proxy({ name: 'Alice' }, logger);
console.log(data.name);  // 输出日志并返回 "Alice"

    # 自动初始化默认值

    const withDefaults = {
  get(target, prop) {
    return prop in target ? target[prop] : 'N/A';
  }
};
const proxy = new Proxy({}, withDefaults);
console.log(proxy.unknownProp);  // 输出 "N/A"

    # 响应式系统（Vue3 原理）

    const reactiveHandler = {
  get(target, prop) {
    track(target, prop);  // 追踪依赖
    return Reflect.get(target, prop);
  },
  set(target, prop, value) {
    trigger(target, prop);  // 触发更新
    return Reflect.set(target, prop, value);
  }
};
function reactive(target) {
  return new Proxy(target, reactiveHandler);
}

    # 四、Reflect 概述

    # 设计目标

    • 统一对象操作：将分散的 Object/Function 方法标准化
    • 与 Proxy 协同：提供与陷阱方法一一对应的默认行为实现

    # 核心方法

    方法 等效操作 返回值
    Reflect.get(obj, 'prop') obj.prop 属性值
    Reflect.set(obj, 'prop', 1) obj.prop = 1 布尔值
    Reflect.has(obj, 'prop') 'prop' in obj 布尔值
    Reflect.construct(Fn, args) new Fn(...args) 实例对象
    Reflect.apply(fn, thisArg, args) fn.apply(thisArg, args) 函数返回值

    # 五、Proxy 与 Reflect 协同使用

    # 解决 this 绑定问题

    const obj = {
  value: 10,
  getValue() {
    return this.value;
  }
};
const proxy = new Proxy(obj, {
  get(target, prop, receiver) {
    return Reflect.get(target, prop, receiver);  // 确保 this 指向代理对象
  }
});
console.log(proxy.getValue());  // 正确输出 10（若直接返回 target[prop]，this 会指向原对象）

    # 简化默认行为调用

    const safeHandler = {
  set(target, prop, value) {
    if (prop === 'id' && !Number.isInteger(value)) return false;
    return Reflect.set(...arguments);  // 直接透传参数
  }
};
const safeProxy = new Proxy({}, safeHandler);
safeProxy.id = 'abc';  // 设置失败

    # 六、注意事项

    # 性能影响

    • 频繁拦截：Proxy 的操作比直接对象访问慢约 2-10 倍，避免在性能敏感场景滥用

    # 深度代理

    • 默认浅代理：需递归代理嵌套对象：
    const deepHandler = {
  get(target, prop) {
    const value = Reflect.get(target, prop);
    return typeof value === 'object' ? new Proxy(value, deepHandler) : value;
  }
};
const deepProxy = new Proxy({}, deepHandler);

    # 可撤销代理

    • Proxy.revocable()：创建可撤销代理：
    const { proxy, revoke } = Proxy.revocable({}, {});
revoke();
proxy.name;  // 抛出错误

    # 不可代理原始值

    • 自动装箱：代理原始值（如字符串）时，目标会被转换为包装对象

    # 七、总结

    特性 Proxy Reflect
    ​用途 拦截对象操作 提供对象操作的默认实现
    返回值 自定义（根据陷阱方法逻辑） 标准化（如布尔值、操作结果）
    设计目标 元编程、行为扩展 操作标准化、与 Proxy 配合

    # 最佳实践

    • 优先使用 Reflect：在 Proxy 陷阱中调用 Reflect 方法以保持默认行为
    • 避免过度拦截：仅在必要时使用 Proxy，关注性能影响
    • 深度代理谨慎使用：递归代理可能引发内存或循环引用问题
